# News Parser

Локальное приложение для парсинга новостей с сайта.  
Сохраняет заголовки и тексты статей в локальную SQLite-базу данных.  
Просмотр через встроенный GUI-интерфейс с тёмной темой.

---

## Требования

- **Python 3.11+**
- Интернет-соединение для загрузки новостей

---

## Установка

### 1. Перейдите в папку проекта

```powershell
cd .\parsing\strana-news
```

### 2. (Опционально) Создайте виртуальное окружение

```powershell
# Создать окружение
python -m venv .venv

# Активировать (PowerShell)
.venv\Scripts\Activate.ps1

# Если появилась ошибка политики выполнения скриптов:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.venv\Scripts\Activate.ps1
```

### 3. Установите зависимости

```powershell
pip install -r requirements.txt
```

Устанавливаемые пакеты:

| Пакет | Назначение |
|-------|-----------|
| `requests` | HTTP-запросы |
| `beautifulsoup4` | Парсинг HTML |
| `sqlalchemy` | ORM для SQLite |
| `PyQt6` | GUI-интерфейс |

---

## Запуск

```powershell
python main.py
```

> **Совет:** Чтобы запускать одной командой из любой папки, создайте файл `run.ps1` в папке проекта:
> ```powershell
> # run.ps1
> Set-Location $PSScriptRoot
> python main.py
> ```
> Затем запускайте: `powershell -File run.ps1`

## Использование

После запуска откроется окно приложения:

```
┌─────────────────────────────────────────────────────────────┐
│  📰 Страна — Читалка   [🔍 Поиск]   [⟳ Обновить]          │
├───────────────────────┬─────────────────────────────────────┤
│  Дата     │ Заголовок │  Текст выбранной статьи             │
│  ...      │ ...       │  (прокручиваемое поле)              │
└───────────────────────┴─────────────────────────────────────┘
│ Статус загрузки...                      Всего в БД: 0       │
└─────────────────────────────────────────────────────────────┘
```

### Первый запуск

1. При первом запуске база данных пустая
2. Нажмите кнопку **⟳ Обновить** для загрузки новостей
3. В строке статуса отображается прогресс загрузки
4. После завершения новости появятся в таблице слева

### Просмотр статей

- **Клик на строку** в таблице → текст статьи отображается справа
- **Ссылка «Открыть в браузере»** под заголовком → открывает оригинал

### Поиск

- Вводите текст в поле 🔍 — таблица фильтруется мгновенно по заголовкам

### Автообновление

Приложение автоматически проверяет новые статьи каждые **30 минут**.  
Повторно скаченные URL в БД не дублируются.

## Настройка

Все настройки находятся в файле [`config.py`](config.py):

```python
AUTO_REFRESH_MINUTES    = 30    # интервал автообновления
DELAY_BETWEEN_REQUESTS  = 0.5   # пауза между запросами (сек)
REQUEST_TIMEOUT         = 15    # таймаут HTTP-запроса (сек)
DB_PATH                 = ...   # путь к файлу базы данных (по умолчанию: news.db рядом с main.py)
```

## Схема базы данных

Файл `news.db` (SQLite) создаётся автоматически при первом запуске.

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | INTEGER | Первичный ключ |
| `title` | TEXT | Заголовок статьи |
| `body` | TEXT | Текст статьи |
| `url` | TEXT UNIQUE | URL статьи (дедупликация) |
| `source` | TEXT | Источник (`ctrana.one`) |
| `published` | DATETIME | Дата публикации |
| `fetched` | DATETIME | Дата сохранения в БД |

## Возможные проблемы

**Ошибка при запуске: `ModuleNotFoundError`**  
→ Убедитесь что зависимости установлены: `pip install -r requirements.txt`

**Новости не загружаются**  
→ Проверьте интернет-соединение и доступность сайта `ctrana.one`

**Кириллица отображается некорректно**  
→ Убедитесь что используется Python 3.11+ и системный шрифт Segoe UI установлен (стандартный для Windows)
